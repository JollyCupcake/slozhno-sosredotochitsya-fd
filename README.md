# Проект "Сложно сосредоточиться"

https://github.com/JollyCupcake/slozhno-sosredotochitsya-fd

## Описание

Проект выполнен, чтобы продемонстрировать навыки создания резиновой вёрстки и адаптивности приложения под разные темы (светлая, тёмная, авто).

## Характеристики

Проект свёрстан в тёмной и светлой темах; дополнительно есть авто-тема, включение которой отображает приложение в тёмной или светлой теме, в зависимости от системных настроек и предпочтений пользователя.

Приложение свёрстано под мобильный, планшетный и десктопные лейауты (375х668, 768x1024, 1024x768).

### Рефлексия

В этом проекте было интересно настраивать резиновую вёрстку с помощью гридов, но было сложно адаптировать сайт под светлую и тёмную тему, при этом учитывая авто-тему в сочетании с пользовательскими предпочтлениями. Чтобы достичь нужного результата, потрбевалось научиться грамотно создавать css-переменные, научиться их правильно переопределять, использовать в корректных файлах.
